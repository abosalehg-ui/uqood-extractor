## نظرة عامة

يتعامل موظفو تحضير الجلسات يومياً مع عشرات النصوص القضائية ذات البنية الموحدة، ويُدخلونها يدوياً في إكسل — وهو عمل متكرر يستهلك وقتاً ويُعرّض البيانات للخطأ البشري.

**مستخرِج بيانات العقود** يحوّل هذه العملية إلى ثلاث خطوات:
ألصق النصوص ← اضغط "استخراج" ← صدِّر إلى إكسل.

تعمل الأداة بالكامل في المتصفح — **لا يُرسَل أي نص إلى خادم خارجي**.

## الاستخدام

### عبر الإنترنت
ادخل على [رابط الأداة](https://abosalehg-ui.github.io/uqood-extractor/) مباشرة.

### محليًّا
لا يحتاج خادماً ولا تنصيباً:
```bash
git clone https://github.com/abosalehg-ui/uqood-extractor.git
cd uqood-extractor
```
ثم افتح `index.html` في أي متصفح حديث.

### خطوات الاستخدام
1. الصق النصوص في مربع الإدخال (افصل بين كل قضية وأخرى بسطر فارغ).
2. اضغط **"استخراج البيانات"**.
3. راجع الجدول — الخلايا الحمراء تعني حقلاً لم يُستخرج، انقر عليها وأدخله يدوياً.
4. اضغط **"تصدير إلى Excel"** أو **"نسخ البيانات"** للصقها في جدول آخر.

> **تجربة سريعة:** اضغط "تحميل عيّنة تجريبية" لتجربة الأداة بنص جاهز.

## البنية النصية المتوقعة

كل سجل قضية يبدأ بـ `موضوع الدعوى` وينتهي بـ `المشفوعات`. يُفصَل بين سجل وآخر بسطر فارغ.

```
موضوع الدعوى
إن موكلي عمل لدى المنشأة المدعى عليها بمهنة ...، وباشر العمل بتاريخ ١٤٣٩/٠٦/١٦هـ،
على أجر فعلي قدره (٥,٩٦٠.٠٠) ... وآخر يوم عمل كان بتاريخ ١٤٤٦/٠٤/٢٣هـ
بسبب إنهاء العقد بلا سبب مشروع.
...
الأسانيد
عقد العمل
المشفوعات

موضوع الدعوى
... (السجل التالي)
```

## الحقول المستخرجة

| الحقل | مصدر النص | مثال |
|---|---|---|
| نوع المطالبة وعددها | بنية "الطلب ... نوع الطلب" | `3 مكافأة نهاية خدمة+تعويض مهلة الإشعار+...` |
| البيِّنات في الدعوى | بين "الأسانيد" و"المشفوعات" | `2 عقد العمل+محضر التسوية` |
| أول يوم عمل | "وباشر/باشرت العمل بتاريخ ..." | `2020-01-19` أو `1441-05-24هـ` |
| آخر يوم عمل | "وآخر يوم عمل كان بتاريخ ..." | `2025-12-31` أو `على رأس العمل` |
| مقدار الأجر | "قدره (الرقم)" | `5960` |
| سبب انتهاء العلاقة | "بسبب ..." | `إنهاء العقد بلا سبب مشروع` |

## الميزات

- **دعم التواريخ الهجرية والميلادية** — يميّز بين `٢٠٢٤/٠١/٠١م` و`١٤٤٥/٠٦/١٩هـ` تلقائياً.
- **تطبيع الأرقام الهندية والفارسية** (٠–٩ و ۰–۹) إلى أرقام لاتينية.
- **دعم "على رأس العمل"** للعقود القائمة التي لا يوجد فيها تاريخ انتهاء.
- **اكتشاف الحقول المفقودة** وتظليلها بالأحمر مع لافتة تنبيه وإحصائيات فورية.
- **تحرير مباشر للخلايا** قبل التصدير بالنقر عليها.
- **تصدير إلى Excel** بصيغة `.xlsx` مع دعم الـ RTL.
- **نسخ الجدول كاملاً أو البيانات فقط** بتنسيق TSV (متوافق مع اللصق المباشر في إكسل).
- **تصميم ثنائي العمود** متجاوب مع شاشات الجوال.
