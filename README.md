## نظرة عامة

تواجه أعمال تحضير الجلسات في المحاكم العمالية كمًّا كبيرًا من النصوص ذات البنية الموحدة (عقود عمل، مطالبات، أسانيد، تواريخ مباشرة وانتهاء). يقوم هذا الجدول عادةً بإدخالها يدويًا في إكسل، وهو عمل متكرر يستهلك وقتًا ويُعرّض البيانات للخطأ البشري.

**مستخرِج بيانات العقود** يحوّل هذه العملية إلى لصق واحد + ضغطة زر:
- ألصق النصوص كما تظهر في تبويب "موضوع الدعوى" (مع فاصل سطر فارغ بين كل قضية وأخرى).
- اضغط "استخراج البيانات".
- راجع الجدول، عدّل ما يلزم بالنقر على أي خلية، ثم صدِّر إلى إكسل أو انسخه.

تعمل الأداة بالكامل في المتصفح — لا يُرسَل أي نص إلى خادم خارجي.

## الميزات

- **استخراج تلقائي لستة حقول** من كل عقد:
  - نوع المطالبة وعددها
  - البيِّنات في الدعوى (الأسانيد)
  - أول يوم عمل (تاريخ المباشرة)
  - آخر يوم عمل (أو "على رأس العمل" للعقود القائمة)
  - مقدار الأجر
  - سبب انتهاء العلاقة
- **دعم التواريخ الهجرية والميلادية** — يميّز بين `٢٠٢٤/٠١/٠١م` و `١٤٤٥/٠٦/١٩هـ` تلقائيًا.
- **تطبيع الأرقام الهندية والفارسية** (٠-٩ و ۰-۹) إلى أرقام لاتينية.
- **اكتشاف الحقول المفقودة** وتظليلها بالأحمر في الجدول مع لافتة تنبيه.
- **تحرير مباشر للخلايا** قبل التصدير (`contenteditable`).
- **تصدير إلى Excel** بصيغة `.xlsx` مع دعم الـ RTL.
- **نسخ الجدول كاملاً أو البيانات فقط** إلى الحافظة بتنسيق TSV (متوافق مع لصق مباشر في إكسل).
- **إحصائيات فورية:** عدد السجلات الكاملة وعدد التي تحتاج مراجعة.
- **تصميم ثنائي العمود** متجاوب مع شاشات الموبايل.

## الاستخدام

### عبر الإنترنت
ادخل على رابط GitHub Pages الموجود في رأس هذا الملف.

### محليًّا
لا يحتاج خادمًا ولا تنصيبًا:
```bash
git clone https://github.com/abosalehg-ui/uqood-extractor.git
cd uqood-extractor
```
ثم افتح `index.html` في أي متصفح حديث.

### عيّنة تجريبية
اضغط زر **"تحميل عيّنة تجريبية"** لرؤية مثال على البنية النصية المتوقعة قبل إدخال بياناتك.

## الحقول المستخرجة

| الحقل | مصدر النص | مثال |
|---|---|---|
| نوع المطالبة وعددها | بنية "الطلب ... نوع الطلب" | `3 مكافأة نهاية خدمة+تعويض مهلة الإشعار+...` |
| البيِّنات في الدعوى | بين "الأسانيد" و "المشفوعات" | `2 عقد العمل+محضر التسوية` |
| أول يوم عمل | "وباشر/باشرت العمل بتاريخ ..." | `2020-01-19` أو `1441-05-24هـ` |
| آخر يوم عمل | "وآخر يوم عمل كان بتاريخ ..." أو "على رأس العمل" | `2025-12-31` أو `على رأس العمل` |
| مقدار الأجر | "قدره (الرقم)" | `5960` |
| سبب انتهاء العلاقة | "بسبب ..." | `إنهاء العقد بلا سبب مشروع` |

## التقنيات

- HTML/CSS/JavaScript خالص — ملف واحد، بدون أي build step.

## نظرة على البنية النصية المتوقعة

كل سجل قضية يبدأ بسطر `موضوع الدعوى` وينتهي بسطر `المشفوعات`. يُفصَل بين كل سجل والذي يليه بسطر فارغ. مثال مختصر:

```
موضوع الدعوى
إن موكلي عمل لدى المنشأة المدعى عليها بمهنة ...، وباشر العمل بتاريخ ١٤٣٩/٠٦/١٦هـ،
على أجر فعلي قدره (٥,٩٦٠.٠٠) ... وآخر يوم عمل كان بتاريخ ١٤٤٦/٠٤/٢٣هـ بسبب إنهاء العقد بلا سبب مشروع.
...
الأسانيد
عقد العمل
المشفوعات
```
